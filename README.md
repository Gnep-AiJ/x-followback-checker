# X 回关助手

一个本地运行的 Chrome 扩展，用颜色标签快速识别 X 关注列表中的互关、未回关和白名单账号。

## 功能

- 红色标签：未回关
- 绿色标签：互关
- 金色标签：白名单，允许对方不回关
- 点击按钮开始、停止或重新扫描
- 搜索、筛选和实时统计已识别账号
- 可拖动的 Bot 工具面板，自动记住位置
- 扫描完成后取消全部滚动任务
- 只扫描“正在关注”主列表，不计入侧栏推荐账号

## 隐私与权限

- 不使用 X API，不需要 API Key
- 不需要服务器或数据库
- 白名单和面板位置仅保存在 Chrome `storage.local`
- 不会自动关注、取关、发帖或上传账号名单
- 仅在 `https://x.com/*` 页面运行

完整说明见 [PRIVACY.md](PRIVACY.md)。

## 运行要求

- 桌面版 Chrome 浏览器
- 已登录的 X 账号
- Chrome 开发者模式

Node.js 不是运行依赖，仅在执行本地测试时需要。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。
6. 刷新 X，进入个人资料的“正在关注”页面。

## 使用

1. 点击面板中的“开始扫描”。
2. 工具会逐页向下读取已加载的关注账号。
3. 到达列表底部，或检测到错误、验证、限流时，扫描自动停止。
4. 点击账号旁的“＋ 白名单”允许该账号不回关；再次点击可移出。

## 工作原理

扩展基于 Chrome Manifest V3 和原生 JavaScript、HTML、CSS。它读取 X 关注列表中的 `UserCell`、取消关注按钮以及 “Follows you / 关注了你” 页面标签进行本地判断。

## 限制

- 依赖 X 当前页面结构；X 改版后可能需要更新选择器或文案。
- X 使用虚拟列表，超大关注列表可能受网络加载速度和平台限制影响。
- 工具不会绕过 CAPTCHA、限流、登录或访问控制。
- 使用浏览器自动化可能受 X 的服务条款约束，使用者应自行确认并承担责任。

## 开发与测试

运行环境不需要构建步骤或第三方依赖。

```powershell
node --test tests/core.test.js
node --check content.js
node --check popup.js
```

## 项目结构

```text

├─ content.js          # 页面扫描、面板和标签逻辑
├─ core.js             # 可测试的纯逻辑函数
├─ styles.css          # 页面面板和标签样式
├─ popup.html          # 扩展弹窗
├─ popup.css
├─ popup.js
├─ tests/
│  └─ core.test.js
└─ PRIVACY.md
```
